# SUROI · 单机增强版（Squad Ops Royal Rumble）

> 一个用原生 ES Module + Canvas 2D 从零实现的 **2D 俯视大逃杀** 网页游戏。
> 玩法数值对齐开源项目 **[HasangerGames/suroi](https://github.com/HasangerGames/suroi)**（GPL-3.0），
> 在此基础上做了大量增强，并补齐了原版缺失的单机/离线游���路径。

**零依赖 · 零构建 · 零外部资源** —— 所有画面由 Canvas 程序化绘制，所有音效由 WebAudio 实时合成。
打开就能玩。

---

## 一秒上手

```bash
# 方式 1：直接开（需要本地服务器，因为用了 ES Module）
cd 项目目录
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000

# 方式 2：发布到 GitHub Pages（见下文「部署」）
```

主菜单可调：**参战人数（9–79）**、**AI 难度（5 档）**、**出生天赋（1–3 个）**、**代号**。

## 从原版 SUROI 移植了什么

数值全部来自原版源码，**不是拍脑袋编的**。

### 武器 · 78 把

`src/data.js` 的 `GUNS` 表对齐原版 `common/src/definitions/items/guns.ts`：
**69 把基础枪 + 9 把双持变体**。每把包含：

- 弹匣容量 / 扩容上限 / 换弹时间（秒）
- 单发伤害 / 射速间隔（ms）/ 射击模式（单发·全自动·三连发）
- 子弹速度（units/ms）/ 有效射程 / 障碍穿透倍率
- 静止散布 / 移动散布（度）/ 后坐倍率 / 后坐时长
- 枪长 / 持枪移速倍率 / 弹药类型 / 稀有度 Tier（S~D）

从 G19 手枪到 ULR-338（单发 185 伤害、0.1° 散布、4.3s 换弹）都原样保留。
霰弹枪的多弹丸 + 散布抖动（`bulletCount` / `jitter`）、双持的左右交替射击、
部分枪械的「首发精准重置」（`fsaReset`）也都实现了。

### 移动与肾上腺素

严格对齐原版 `server/src/objects/player.ts` 的对数回归模型：

```
speedMod = b·ln(adrenaline + d) / ln(c) + a      // 速度倍率
hpRegen  = a + b·ln(adren + d) / ln(c)           // 每秒回血
```

- 基础速度 `0.03 units/ms`（= 30 units/s）
- 持枪减速 0.88 / 近战 1.0 / 持投掷物 0.92
- 肾上腺素自然衰减 0.5/s，满值 100
- 对角线移动归一化 `×√½`
- 冰面减速、水中减速

### 毒圈 · 13 阶段

对齐 `server/src/data/gasStages.ts` 的完整时序表：

| 阶段 | 等待(s) | 收缩半径系数 | DPS | 空投 |
|---|---|---|---|---|
| 1 | 75 | 0.76 → 0.55 | 0 | — |
| 3 | 45 | 0.55 → 0.43 | 1 | ✔ |
| 5 | 40 | 0.43 → 0.32 | 2 | — |
| 7 | 35 | 0.32 → 0.20 | 3 | ✔ |
| 9 | 30 | 0.20 → 0.09 | 5 | — |
| 11 | 20 | → 0 | 10 | ✔ |

最终圈在约 **6 分 30 秒**关闭。圈内伤害公式也一致：
`dps + max(圈外深度 - 12, 0) × 0.005`，越深入圈外伤害越高。

### 护甲 / 治疗 / 背包 / 瞄具

- **8 种护甲**：头盔 1–4 级（减伤 10%–25%）、护甲 1–4 级（20%/35%/45%/35%）
- **5 种治疗品**：绷带(+20, 3s)、医疗包(回满, 6s)、可乐(+25 肾上腺素, 3s)、兴奋剂(+50, 4s)、疫苗
- **4 级背包**：容量从 Bag 到 Tactical Pack
- **5 档瞄具**：1x/2x/4x/8x/16x，驱动相机缩放

### 掉落权重

对齐 `server/src/data/lootTables.ts`：G19 权重 2（最常见），
Tactical 级装备权重仅 0.01（极稀有），S 级枪不在普通掉落表、只能从空投拿。
另有 22 把空投专属枪池（PP-19 Bizon、ACR、ULR-338、Death Ray…）。

### 其他

- **14 种近战武器**（棒球棍伤害 34、火斧 50、HE-AP 剑 75…）
- **6 种投掷物** + 完整爆炸定义（破片数、破片伤害、破片速度、遮挡射线检测）
- **可破坏物**：木箱、油桶（连锁爆炸）
- **地形**：海洋、沙滩、河流（减速）、冰面（减速）、森林、岩石、城镇街区
- **灌木潜行**：藏进灌木后 90 单位外不会被发现
- **补给容器**：走近自动搜刮
- **空投**：降落伞动画 → 落地散落 3–5 件

## 增强了什么（原版没有 / 做得更好）

### 1. 单机化

原版是 Bun + WebSocket 多人联机，必须起服务端。本作把全部逻辑跑在浏览器里，
AI 接管了联机版的对手角色——**一个人打开网页就能玩完整大逃杀**。

### 2. 完整的 AI 状态机

原版客户端无 AI（依赖真人）。本作给 39–79 个 Bot 写了：

- **6 态状态机**：`LOOT` 舔包 → `ROTATE` 跑圈 → `ENGAGE` 交战 → `HUNT` 追杀残血 → `COVER` 找掩体 → `FLEE` 逃跑
- **5 档难度曲线**：反应延迟 0.55s→0.10s、瞄准误差 0.42rad→0.055rad、
  找掩体倾向 0.15→0.9、毒圈意识 0.4→1.0
- **掩体选择**：扫描障碍物，评估「离威胁距离 / 自身距离」的性价比选点
- **绕障**：前方有墙时先探左右哪边通
- **按武器智能交战距离**：霰弹枪贴脸 32，栓动狙拉到 260
- **掉落价值评分**：按「缺口 × 稀有度 − 距离」打分选目标，不做无脑捡垃圾
- **战术动作**：换弹时后撤拉扯、低血嗑药、投掷物、命中闪避
- **AI 走的是和玩家完全相同的代码路径**（输出伪装成玩家输入结构）

### 3. 新增 11 个天赋（原版 15 → 共 26）

保留原版全部（Second Wind、Sabot Rounds、Berserker、Overclocked…），新增：

| 天赋 | 效果 |
|---|---|
| Iron Lung | 最大生命 +40，肾上腺素上限 +40 |
| Swift Feet | 移速 +18%，冲刺冷却 −40% |
| Vampiric | 击杀恢复 30 生命 + 30 肾上腺素 |
| Scavenger | 击杀掉落一个空投补给箱 |
| Last Stand | 受到致命伤时免疫一次并回复 40 生命 |
| Executioner | 对生命低于 40% 的敌人伤害 +25% |
| Ammo Scavenger | 拾取弹药时额外获得 50% |
| Zone Walker | 毒圈伤害 −60% |
| Field Medic II | 每秒固定回复 1.5 生命（不依赖肾上腺素） |
| Loot Baron | 拾取范围 +60% |
| Toploaded | 移速 +12%，肾上腺素上限 +25 |

**天赋数量上限从 1 个放宽到 3 个**，作为「增强」路线的核心一环。

### 4. 冲刺闪避（Dash）

原版**完全没有** dash/翻滚机制（我通读 3332 个文件确认过）。
本作新增：3s 冷却、3.4× 速度冲刺 0.16 秒，带残影特效，可用于躲子弹和拉开距离。

### 5. 连杀系统

连续击杀累积加速光环，2 杀起显示橙色环，3 杀播报。这让后期交火更有节奏感。

### 6. 手感细节

- **固定步长 120Hz 累加器**——保证 79 个 AI + 数百发弹丸下手感一致，不因帧率波动而穿透
- **顿帧（hitstop）**：击杀时 0.14s 顿帧 + 0.25 倍慢动作
- **程序化枪声**：按武器 Tier 合成 5 种音色（噪声 + 锯齿 + 方波三层）
- **屏幕震动 / 闪光 / 暗角 / 弹道拖尾 / 血雾 / 伤害飘字**
- **空间网格**索敌，避免 O(n²)

## 项目结构

```
suroi-game/
├── index.html            # UI 骨架 + 全部 CSS 主题变量
└── src/
    ├── data.js           # 78 把枪 / 弹药 / 护甲 / 治疗 / 背包 / 瞄具 / 天赋 / 毒圈表 / 掉落权重
    ├── core.js           # 数学工具 · WebAudio 音频引擎 · 粒子系统 · 空间网格 · 线段碰撞
    ├── world.js          # 地图程序化生成 · 障碍物 · 掉落物 · 毒圈状态机
    ├── entities.js       # Player / Bullet / Throwable / 爆炸结算
    ├── ai.js             # AI 参数曲线 + 6 态状态机
    ├── game.js           # 固定步长主循环 · 状态机 · 拾取 · 击杀结算 · 空投 · 相机
    ├── render.js         # 俯视 2D 渲染 · HUD · 小地图 · 计分板 · 播报
    └── main.js           # 输入（键鼠/触屏）· 菜单 · 结算 · 音效绑定
```

各模块职责单一，`data.js` 是纯数据表，想改数值平衡直接改这一个文件。

